AI-Powered Customer Churn Prediction & Retention Strategy System
Overview
SmartRetain AI is an intelligent decision-support system that predicts customer churn risk and automatically generates personalized retention strategies using machine learning and Large Language Models (Amazon Nova).
The platform helps businesses proactively identify at-risk customers and recommend targeted actions to improve customer retention and revenue.
Key Features
	•	 Customer Churn Prediction using Machine Learning
	•	 Risk Classification (Low / Medium / High)
	•	 AI-Generated Retention Strategy using LLM
	•	 Personalized Customer Messaging
	•	 Business Impact Estimation
	•	 Interactive Streamlit Web Interface
	•	 Downloadable Results (CSV)
System Architecture
User Input → ML Model → Risk Prediction → AI Strategy Generator → Dashboard Output
Technologies:
	•	Python
	•	Scikit-learn
	•	Streamlit
	•	Pandas
	•	AWS Bedrock / Amazon Nova (LLM)
	•	Joblib
Machine Learning Model
The churn prediction model is trained on the Telco Customer Churn dataset using supervised learning techniques.
Model Output:
	•	Churn Probability
	•	Risk Level Classification
AI Retention Engine
The AI module analyzes:
	•	Customer profile
	•	Service usage
	•	Contract information
	•	Predicted churn risk
Then generates:
	•	Recommended offers
	•	Retention actions
	•	Customer communication message
	•	Expected business impact
